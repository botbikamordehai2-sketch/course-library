# AI Essentials — Practical Study Guide, Module 1

## Source status
Imported from an existing Notion study page. This is a concise public-safe summary, not a transcript.

## Main themes
The module groups three themes: philosophy of AI, representations of AI in science fiction, and a Python foundations refresh. The notes emphasize the difference between narrow AI and AGI, and the need to measure systems against a defined task rather than judging them by fluency.

## Key concepts
- **Narrow AI:** specialized capability within a bounded task/domain.
- **AGI:** a hypothetical general system able to adapt and transfer knowledge broadly; the source notes say there is no agreed proven AGI today.
- **Turing Test:** conversational behavior can show human-like interaction but does not prove understanding, consciousness, or factual reliability.
- **Human-in-the-loop:** human review or approval at critical decision points.
- **Object / Type:** core Python concepts used to reason about values and valid operations.

## Evaluation checklist
1. Define the task and measurable success.
2. Test on new examples, not only known demonstrations.
3. Separate FACT / OBSERVATION / INFERENCE.
4. Verify important sources and calculations independently.
5. Restrict permissions and define fail-closed behavior.
6. Require human approval for high-impact or irreversible actions.

## Project relevance
Useful for NEXUS governance because it separates apparent intelligence from reliable capability and turns evaluation into measurable checks rather than impressions.
