# Notion → Public GitHub migration

## Objective
Create a public-safe course knowledge base from the private Notion workspace.

## What is exported
- original summaries
- study plans
- public course titles and links
- project-specific reflections
- original exercises/checklists
- migration status

## What is not exported
- private Notion URLs
- account information
- cookies/session data
- credentials
- full transcripts
- full lesson text
- downloaded paid-course media
- material that would expose private project secrets

## Source-of-truth rule
Notion remains the private source workspace. GitHub is the public learning mirror.

## Verification states
- **IMPORTED:** public-safe content has been migrated.
- **INVENTORY_ONLY:** course/page was discovered but detailed notes have not yet been exported.
- **UNVERIFIED:** title/link/topic exists in notes but requires re-checking.
